# 編輯工具第三版

使用者已確認自動解鎖與單行排版方向。

- 預覽預設及重設為 30%，保留 1080 × 1350 輸出。
- API Key 可選擇加密儲存；Web Crypto AES-256-GCM、每次新 IV、不可匯出的 CryptoKey，與密文原子寫入獨立 IndexedDB。下次自動解鎖，設定介面明示同來源程式仍可解密。支援僅本次使用與清除本機金鑰。絕不寫進專案、草稿或原始碼。
- 增加已核對 OFL 授權的中英文字型；保留思源黑體預設，主、副文字各自選擇，提供授權原文。
- 新語錄預設主、副各一行，過長整組縮小；可切換允許換行。舊專案保留原換行設定。
- 每段可選一般、引號、引用框，並填作者／講者與來源。來源不會被當作 HTML 或命令；AI 不得捏造引述。
- 專案入口提供 JSON 儲存與載入，完整保存編輯資料及本機上傳圖；API Key 不匯出。PNG 與 ZIP 保持原流程。
- 專案格式升級為 3，仍可匯入第 1、2 版。

## 執行與驗證

1. 字型／專案結構／排版：先測試版本升級、單行縮字、手動換行、引用出處保存，再實作。
2. 加密儲存：測試非明文、不可匯出、隨機 IV、竄改拒絕；瀏覽器驗證重新開啟、清除與資料庫原文。
3. 介面與輸出：桌機／手機、專案往返、PNG／ZIP、字型載入及舊稿。
4. 獨立審查，修正後推送 main 並驗證 GitHub Pages。
