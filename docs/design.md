# 慢慢 studio

依使用者要求直接製作。React + Vite、TypeScript，純前端，資料留在使用者瀏覽器。

- 目的：製作 4:5、1080 × 1350 的復健／療癒 IG 輪播。
- 視覺：白色面板、淺灰畫布、深綠主色、低彩度照片與白色宋體。左側頁面清單、中間預覽與縮圖、右側編輯器。
- 手動流程：新增／複製／排序頁面 → 選單圖、上下、左右、文字版型 → 編輯兩段文字與圖片 → 匯出單張 PNG 或整組 ZIP。
- 圖片：內建 Unsplash 免費授權示範圖；免金鑰 Wikimedia CC0 搜尋；選填 Pexels Key；本機上傳與網址輸入。保留來源授權資訊。
- AI：直接呼叫 OpenRouter；載入可用文字模型、選擇模型與頁數、輸入提示詞，驗證 JSON 後產生可編輯輪播。圖片使用圖庫搜尋，不假裝生成新照片。
- 金鑰：可僅本次使用，或選擇 AES-256-GCM 本機加密及自動解鎖。不寫入草稿、原始碼、匯出專案或 localStorage；自動解鎖的 CryptoKey 存於同一瀏覽器，保護邊界見第三版設計。
- 驗證：AI 輸出與專案匯入邊界、4:5 匯出、編輯與排序、本機圖片、桌機／手機瀏覽器流程。

採純前端而非後端帳號服務，以符合簡易工具範圍。每位使用者提供自己的 API Key；公開給多人共用服務端 Key 時應另設後端代理。
