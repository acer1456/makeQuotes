# 畫布文字操作

直接點選每段語錄，拖曳整組位置；選取框右下「主」控制點調主文字字級，左下「副」控制點調副文字字級。單語時只顯示主文字控制點。右側同步選中該段，保留字級與位置數值設定。

操作使用與 PNG 相同的實際排版邊界，按目前縮放換算座標。移動限制於該段版面區域，保留原本單行自動縮字與主副字級限制。桌機與觸控共用 Pointer Events；背景仍可捲動。

拖曳中只預覽，放開才建立一次可復原的變更。Escape、pointercancel 或失去 pointer capture 取消操作。選取框與控制點不繪入匯出圖片；專案格式維持第 3 版。

驗證：座標換算、各版型移動限制、字級上下限；瀏覽器測試拖曳、獨立字級、復原、取消、縮放、觸控、重新載入與 PNG／專案匯出。
