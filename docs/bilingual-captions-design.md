# 雙語語錄

沿用已確認的雙語示意與既有編輯器。每個圖片區塊各有一組中文與英文；主文字在上、副文字在下。支援中主英副、英主中副、僅中文、僅英文；模式切換保留兩種語言原文。

新語錄預設主文字 56 px、副文字 34 px、間距 26 px。使用者確認字型可選，主、副文字預設均為思源黑體，也可各自改成思源宋體。副文字字級必須小於主文字。

模式可逐頁設定，亦可套用全部頁面。單語模式只隱藏另一語言，不刪除內容。每段中文與英文分開輸入；英語依單字換行。主、副文字共用一個位置與對齊，作為一組排版，避免互相覆蓋；長文整組等比縮小。

AI 一次生成每段語錄的中英對照。使用者選擇生成後的顯示模式，結果仍可逐頁修改。保留既有 API Key、照片來源與安全處理。

資料升級至第 2 版。第 1 版草稿與匯入專案保留原文字、樣式與位置，初始以僅中文顯示；不假裝已翻譯。缺少英譯時顯示提醒。預覽及 PNG 使用同一套排版。
